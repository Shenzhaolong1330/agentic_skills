当前公共 smooth P2P：

1. 每次调用开始仍用 `step(None)` 同步双臂目标，以返回的观测为首段起点，防止追逐旧目标。
2. 一段所有 waypoint 收到回复后，保存其命令终点。下一轮从该已确认命令终点追加
   实测残差的 0.6 倍，不再次归零；单轮平移补偿最多 3 mm、姿态最多 0.03 rad。
3. 命令补偿相对用户原请求终点累计最多 25 mm / 0.20 rad；接近边界时分别缩小平移/旋转步长，

   实际到位检查始终比较原请求终点，不把补偿终点当作成功标准，不放宽容差。
4. LostRemote / 同步失败 / 回包不完整不重试未知动作，不恢复控制器或开夹爪。

补偿界限不是碰撞保护。真机仍需验证，不能从带固定偏差的模拟模型推断现场一定收敛。
